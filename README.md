# Embodied graph experiments

Each paper has its own repository, release archive and offline verification script.

| Study | Repository | Reproducibility release |
| --- | --- | --- |
| Paired action responses in contact-graph world models<br>Yunjian Zhang, Ying Liu, Aobo Li, Yilun Wu, Mu-Jiang-Shan Wang | [contact-graph-action-responses](https://github.com/LudwigWangMu/contact-graph-action-responses) | [v1.0.1](https://github.com/LudwigWangMu/contact-graph-action-responses/releases/tag/v1.0.1) |
| Episode-calibrated action prefixes from robot-object graph forecasts<br>Aobo Li, Ying Liu, Yunjian Zhang, Yilun Wu, Mu-Jiang-Shan Wang | [episode-calibrated-action-prefixes](https://github.com/LudwigWangMu/episode-calibrated-action-prefixes) | [v1.0.1](https://github.com/LudwigWangMu/episode-calibrated-action-prefixes/releases/tag/v1.0.1) |
| Reusing scene-graph readouts across asynchronous robot updates<br>Yilun Wu, Ying Liu, Yunjian Zhang, Aobo Li, Mu-Jiang-Shan Wang | [scene-graph-readout-reuse](https://github.com/LudwigWangMu/scene-graph-readout-reuse) | [v1.0.1](https://github.com/LudwigWangMu/scene-graph-readout-reuse/releases/tag/v1.0.1) |
| Decision-relevant symmetry breaking on navigation graphs | [decision-relevant-symmetry-breaking](https://github.com/LudwigWangMu/decision-relevant-symmetry-breaking) | [v1.0.0](https://github.com/LudwigWangMu/decision-relevant-symmetry-breaking/releases/tag/v1.0.0) |

In each downloaded release, run `python verify.py` from the extracted root using Python 3.12. Full experimental reproduction instructions appear in the corresponding README.

Earlier manuscript links referring to the combined [v1.0.0 archive](https://github.com/LudwigWangMu/embodied-graph-experiments/releases/tag/v1.0.0) remain available.
